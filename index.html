CRISP-DM Phase 5 & 6: Evaluation & Final Project Conclusions

專案決策洞察、統計推論檢定、奧卡姆剃刀精簡分析與 AIoT 未來整合方向
閱讀 Conclusions.md 驗證腳本 .py GitHub Repo

1. 商業與管理決策洞察

  • 研發支出為獲利關鍵核心：研發與淨利相關係數高達 0.973，每投入 $1 美元，預期邊際貢獻約 +$0.79 美元 (p < 0.0001)。
  • 行政管理費用中立：係數接近 0 且未達統計顯著 (p > 0.05)，草創與成長階段過度擴張行政支出無法轉化為利潤。
  • 地理位置不敏感：紐約、加州、佛州三地虛擬變數皆不顯著，雲端與數位營運下實體位置非決定獲利之關鍵門檻。

2. 奧卡姆剃刀與特徵精簡

  • 5 種演算法高度一致：Lasso、Forward SFS、RFE、ElasticNet、Exhaustive Search 皆排序 R&D 與 Marketing 為前兩大特徵。
  • 全局最佳甜蜜點 (k=2)：最低測試 RMSE ($8,198.80) 與最高 R² (0.9474)，調整後 R² 達 0.9324。
  • 過擬合峭壁警示 (k=5)：納入無效變數導致測試 RMSE 顯著跳升至 $9,055 ~ $9,138，證明少即是多（Less is more）。

3. 研究局限性分析

  • 樣本規模局限 (N=50)：樣本量偏小，極端值（如高研發低利潤個案）對迴歸超平面具有較大槓桿影響力。
  • 線性假定之侷限：普通最小平方法 (OLS) 未能捕捉研發投入之邊際報酬遞減或門檻躍升效應。
  • 存活者偏差 (Survivorship Bias)：僅調查持續營運並獲利之新創企業，排除倒閉案例，結果可能帶有樂觀偏誤。

4. 未來延伸與 AIoT 整合

  • 整合物聯網即時遙測：從靜態財報擴展至工廠設備稼動率、雲端算力消耗量、邊緣感測器頻寬等高頻即時數據。
  • 導入現代非線性集成演算法：引入 XGBoost / LightGBM 捕捉特徵交互作用，結合 SHAP 進行模型可解釋性分析。
  • 端到端即時決策系統部署：將 Pipeline (startup_profit_lr.pkl) 串接 REST API，提供動態預算情境模擬。
